3.1 Графіка для вебсередовища

Розподіл на растрові та векторні дані, математика стиснення файлів і забезпечення чіткого відображення на дисплеях із високою щільністю пікселів (HiDPI / Retina).

Порівняння масштабування: Растр проти Вектора

Масштаб: 100%
Растр (PNG / Bitmap) Піксельна матриця

При збільшенні проявляється пікселізація та артефакти розмиття ліній.

Вектор (SVG / XML) Математичні координати

Лінії та криві перераховуються динамічно зі збереженням ідеальної чіткості.

Огляд вебформатів

Формат Тип Стиснення Прозорість Сфера застосування
SVG Векторний Текстове (Gzip/Brotli) Альфа-канал Піктограми, логотипи, діаграми, елементи UI
WebP Растровий Lossy / Lossless Так (8-біт) Основні фотографії сайту, банери, обкладинки
AVIF Растровий Високоефективне (AV1) Так (HDR/10-біт) Нове покоління фотографій (максимальне стиснення)
PNG Растровий Без втрат (Deflate) Альфа-канал Скриншоти з текстом, графіка з чіткими межами
JPEG Растровий Із втратами (DCT) Ні Фотографії та рендери без потреби прозорості

Адаптивні зображення: елемент <picture>

Контейнер <picture> дозволяє браузеру вибрати найкраще зображення залежно від ширини екрана та підтримки сучасних форматів без надлишкового трафіку. 

<picture>
  <source media="(min-width: 960px)" srcset="photo-large.avif" type="image/avif">
  <source srcset="photo-mobile.webp" type="image/webp">
  <img src="fallback.jpg" alt="Опис" loading="lazy" width="800" height="500">
</picture>

Анімаційні ефекти

Властивості CSS для побудови відгукливого інтерфейсу: керування станами через transition, оптимізовані перетворення transform та нелінійні послідовності з @keyframes.

Параметри ефекту

2D Transform
CSS властивості: 
.element {
  animation: rotateAnim 1.0s ease infinite;
}

@keyframes rotateAnim {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

transition

Задає плавний перехід між двома станами елемента (наприклад, стан за замовчуванням та псевдоклас :hover або :focus).

transition: transform 0.25s ease;

transform

Виконує зміщення, поворот чи масштабування у просторі. Обробляється безпосередньо графічним процесором (GPU) без перерахунку структури сторінки.

transform: translate3d(0, -4px, 0);

@keyframes

Дозволяє описувати складні послідовності з будь-якою кількістю проміжних кроків від 0% до 100% з циклічним повторенням.

animation: pulse 1.5s infinite;

3.2 Мультимедіа на вебсторінках

Використання нативних стандартів HTML5 для інтеграції медіапотоків без плагінів, адаптивні відеоконтейнери та ізоляція зовнішніх сервісів через <iframe>.

HTML5 <audio>

Відтворення звуку

Підтримка форматів MP3, WAV, AAC, Ogg. Керування гучністю, автоматичний буфер та доступність для клавіатурної навігації.

Генератор аудіопотоку Web Audio Чистий вебстандарт (без зовнішніх MP3)
Гучність:
<audio controls preload="metadata"><source src="audio.mp3" type="audio/mpeg"></audio>
HTML5 <video>

Відеопрогравач

Атрибути playsinline (відтворення всередині сторінки на смартфонах), poster (заставка до запуску) та controls.

Готовий
00:00 / 00:10
<video controls poster="cover.jpg" playsinline><source src="clip.mp4"></video>
HTML5 <figure>

Семантика зображень

Обгортка <figure> та <figcaption> забезпечує структурований зв’язок графіки з текстом сторінки.

<figure><img src="..." alt="..."><figcaption>Підпис</figcaption></figure>
HTML5 <iframe>

Ізольований фрейм

Вбудовування сторонніх карт чи віджетів. Атрибут sandbox запобігає несанкціонованому виконанню небезпечних дій.

sandbox://isolated-subdocument
<iframe src="..." loading="lazy" sandbox="allow-scripts"></iframe>
