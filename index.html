Тема 3.1

Графіка для вебсередовища

Фундамент візуального сприйняття вебсайтів: принципи роботи з растровими й векторними даними, підбір оптимального формату та стиснення.

🔬 Інтерактивний компаратор: Растр vs Вектор (SVG)

Рухайте повзунок масштабу, щоб побачити, як растрове зображення пікселізується при збільшенні, тоді як SVG залишається бездоганно чітким на будь-якому екрані.

Растровий формат (PNG/JPG)

⚠️ При збільшенні виникає розмиття та видимість окремих пікселів.

Векторний формат (SVG)

✅ Математичні криві перераховуються без найменшої втрати якості.

Основні формати вебграфіки

SVG

Векторна графіка (XML)

Scalable Vector Graphics — текстовий XML-формат для описів кривих, ліній та форм. Не втрачає якість при будь-якій роздільній здатності.

Прозорість: Так (альфа-канал)
Анімація: Так (CSS / JS / SMIL)
Найкраще для: Логотипи, піктограми, діаграми
WebP

Сучасний веб-растр

Формат від Google зі стисненням із втратами та без втрат. На 25-35% легший за старі формати при однаковій візуальній чіткості.

Прозорість: Так
Анімація: Так
Найкраще для: Основні фото та банери сайтів
PNG

Растр без втрат (PNG-24)

Ідеальний для зображень із високою деталізацією, текстом, графікою та напівпрозорими градієнтами, де втрата якості неприпустима.

Прозорість: Так (8-біт альфа)
Анімація: Обмежено (APNG)
Найкраще для: Скриншоти, схеми з текстом
JPG / JPEG

Класичний фото-растр

Формат стиснення з втратами. Відмінно підходить для цифрових фотографій із мільйонами кольорів та складними світлотінями.

Прозорість: Ні
Анімація: Ні
Найкраще для: Галереї фотографій, фонові знімки

Практична робота №7

Тема: Графіка для вебсередовища

🎯 Мета роботи

Навчитися ефективно вбудовувати та оптимізувати растрові й векторні графічні ресурси на вебсторінці; опанувати синтаксис інлайнового коду SVG, побудову багатошарових адаптивних структур за допомогою тегу <picture> та оптимізацію завантаження за допомогою атрибута loading="lazy".

📖 Основні поняття

  • Векторний примітив: геометрія <rect>, <circle>, <path>.
  • Viewport & viewBox: координатна сітка SVG для масштабування без спотворень.
  • Атрибут srcset: перелік файлів різної щільності пікселів (1x, 2x) або ширини.
  • Елемент <picture>: контейнер для вибору джерела згідно медіазапитів.

💻 Зразок робочого коду

<picture>
  <source media="(min-width: 800px)" srcset="large.webp">
  <source srcset="small.webp">
  <img src="fallback.jpg" alt="Ілюстрація" loading="lazy">
</picture>

📋 Покрокове завдання

1
Створення SVG-іконки: побудуйте власну векторну фігуру за допомогою тегів <svg>, <circle> та <rect> або налаштуйте параметри в тренажері нижче.
2
Адаптивна графіка: організуйте структуру <picture> для перемикання графіки під мобільні та настільні екрани.
3
Оптимізація та семантика: вкажіть інформативний alt та додайте loading="lazy" для відкладеного завантаження.
🧪 Інтерактивний стенд: SVG Генератор

Тема: Анімація

Анімаційні ефекти

Оживлення інтерфейсів через плавні переходи transition, трансформації transform та нелінійні сценарії @keyframes.

⏳

1. CSS Transition

Плавна зміна CSS-властивостей між двома станами (наприклад, при наведенні курсору :hover або зміні класу).

transition: all 0.3s ease-in-out;
  • transition-property
  • transition-duration
  • transition-timing-function
🔄

2. CSS Transform

Геометричні маніпуляції елементом без перерахунку макета сторінки (висока продуктивність завдяки GPU-акселерації).

transform: scale(1.1) rotate(45deg);
  • translate(x, y) — зміщення
  • rotate(deg) — поворот
  • scale(factor) — масштабування
🎬

3. Keyframes (@keyframes)

Багатофазні складні анімації з контролем проміжних точок за відсотками (від 0% до 100%) або from / to.

animation: pulse 2s infinite ease;
  • @keyframes myAnim { ... }
  • animation-iteration-count
  • animation-direction: alternate

🎮 Інтерактивна лабораторія анімацій

Оберіть потрібний ефект, щоб протестувати його в реальному часі та переглянути згенерований CSS-код.

Оберіть анімаційний ефект:
CSS Object
Згенерований CSS код: 
.animated-actor {
  animation: rotateAnim 1.2s ease-in-out infinite;
}
@keyframes rotateAnim {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

Практична робота №8

Тема: Анімаційні ефекти

🎯 Мета роботи

Опанувати практичні навички створення веб-інтерфейсів з активною мікро-взаємодією: побудова інтерактивних кнопок, карток з 3D-ефектами, індикаторів завантаження (spinners) та сценаріїв безперервної анімації засобами чистого CSS3.

📖 Теоретичний мінімум

  • Оптимізація продуктивності: анімації на властивостях transform та opacity не спричиняють повторного рендеру сторінки (reflow/layout).
  • Керування шарами: властивість will-change: transform; готує графічний процесор до навантаження.
  • Timing functions: криві Безьє cubic-bezier() для природності руху.

💻 Зразок анімованої кнопки

.glow-button {
  transition: all 0.3s ease;
  transform: translateY(0);
}
.glow-button:hover {
  transform: translateY(-4px) scale(1.03);
  box-shadow: 0 10px 25px rgba(6,182,212,0.4);
}

📋 Покрокове завдання

1
Створення картки товару/послуги: реалізуйте ефект плавного спливання (підйому) картки та появи тіні при наведенні курсору.
2
Пульсуючий маркер: створіть нескінченно анімований індикатор активності (Live indicator) за допомогою @keyframes.
3
Індикатор завантаження: створіть власний круговий спінер (loading spinner) з безперервним обертанням на 360 градусів.

Тема 3.2

Мультимедіа на вебсторінках

Інтеграція аудіо-треків, відео-потоків, високоякісних зображень та зовнішніх ресурсів за допомогою стандартів HTML5.

🎵 HTML5 Audio

Аудіоплеєр на вебсторінці

Тег <audio> забезпечує вбудоване відтворення звуку (MP3, WAV, OGG) без сторонніх плагінів. Підтримує атрибути controls, autoplay, loop, muted.

Навчальний звуковий зразок
Синтезатор частот Web Audio API
Гучність:
<audio controls> <source src="track.mp3" type="audio/mpeg"> </audio>
🎬 HTML5 Video

Відеопрогравач із керуванням

Тег <video> відтворює MP4, WebM, Ogg. Дозволяє задавати фонову обкладинку (poster), субтитри <track> та режим картинки в картинці.

Готовий до відтворення
00:00 / 00:15
<video controls poster="preview.jpg"> <source src="film.mp4" type="video/mp4"> </video>
🖼️ Адаптивне зображення

Сучасний контейнер зображень

Використання семантичного контейнера <figure> з підписом <figcaption>, підтримка темної теми та плавний ефект збільшення при наведенні.

🌐 Інтерактивний iframe

Вбудований фрейм (Iframe)

Тег <iframe> вбудовує сторонні карти, віджети або окремі HTML-документи. Обов'язково використовуйте атрибути loading="lazy" та sandbox для безпеки.

sandbox://interactive-calculator.html
<iframe src="..." loading="lazy" sandbox="allow-scripts"></iframe>

Практична робота №9

Тема: Мультимедіа на вебсторінках

🎯 Мета роботи

Опанувати стандарти вбудовування мультимедійного контенту на вебсторінках; навчитися налаштовувати HTML5 аудіоплеєр та відеоплеєр із набором параметрів, підключати альтернативні джерела файлів (fallback), інтегрувати сторонній інтерактивний контент через захищений iframe.

📖 Теоретичні акценти

  • Кросбраузерність: використання декількох тегів <source> для MP4 (H.264) та WebM (VP9/AV1).
  • Атрибут autoplay: сучасні браузери блокують автоматичне відтворення зі звуком, тому завжди додають muted.
  • Політика безпеки: атрибут sandbox у тезі iframe запобігає XSS-атакам.

💻 Зразок повного відеоблоку

<video controls width="640" poster="cover.jpg" preload="none">
  <source src="clip.webm" type="video/webm">
  <source src="clip.mp4" type="video/mp4">
  Ваш браузер не підтримує відео.
</video>

📋 Покрокове завдання

1
Створення медіа-контейнера: побудуйте розмітку з елементом <audio>, увімкненими елементами керування controls та альтернативним текстом для старих браузерів.
2
Налаштування відео: додайте елемент <video> з постером, обмеженням розміру та властивістю playsinline для мобільних пристроїв.
3
Інтеграція віджета iframe: додайте вбудований елемент з картою чи інтерактивним віджетом, встановивши параметри loading="lazy" та allowfullscreen.
